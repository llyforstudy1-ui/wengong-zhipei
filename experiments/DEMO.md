# 稳供智配演示顺序

建议录制约3分钟，按实际页面运行节奏调整停顿。模型全部采用设定参数。

| 时间 | 操作 | 讲解要点 |
|---|---|---|
| 00:00—00:25 | 展示仓库、四工位和参数区 | 四个加工工位持续消耗物料，共用一辆配送车。系统在库存下降到阈值时产生补料申请。 |
| 00:25—01:00 | 选择风险＋等待，点击开始；出现派车后暂停 | 派车评分结合预计缺料时间、装卸运输时间以及已经等待的时间。候选表记录决策瞬间的数值，便于解释选择原因。 |
| 01:00—01:30 | 继续播放，展示到达、卸料和复工；再运行至结束 | 物料在卸料结束时入库，工位有料后恢复加工。库存、车辆位置和统计来自同一个运行模型。 |
| 01:30—02:10 | 打开策略对比，计算完整60分钟 | 三种策略使用相同输入。原始平稳场景下，风险与等待和先申请先送停工均约86.85工位·分钟，原始风险优先约98.55。当前结果说明等待因素可以改善原始风险排序，但仍需比较不同条件。 |
| 02:10—02:40 | 展示理论运力负荷；把车速改为2，再运行对比 | 原车速下，维持连续生产所需的理论配送工时达到单车可用工时的172.2%。调整车速后重新估算负荷并观察实际停工，讨论运力与配送顺序的共同作用。具体结果以页面计算为准。 |
| 02:40—03:00 | 导出对比CSV，展示MATLAB扩展实验目录 | MATLAB用于独立复核和参数扫描，网页用于观察过程与解释调度。保留各工况完整结果，帮助判断策略的适用条件。 |

录制前将网页刷新至v0.3。暂停查看派车时，可在事件产生后调整播放倍速。参数变动会重置运行，应先展示当前结果或导出CSV。
