# 稳供智配

小型加工车间缺料预警与配送调度仿真系统，浏览器仿真原型 v0.2。

## 使用方法

在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，设置 main 分支及 / (root)，保存后打开 GitHub 显示的网站地址。

1. 点击“开始仿真”，观察四工位库存与配送车运行。
2. 暂停后查看派车候选与选择依据，支持继续、重置和直接运行至结束。
3. 切换“策略对比”，计算两种策略完整60分钟结果。
4. 可选择平稳生产、工位B局部加速、配送紧张，调整车速和播放倍速。
5. 导出CSV，保留参数、统计、事件及库存时间序列。

## 模型范围

单仓库、四工位、单配送车、固定线路，每趟一盒12件。工位开工扣料、加工完成计产量，卸料结束入库，随后车辆返仓。运输和加工事件按连续时间处理，界面按1秒采样。倍速只影响播放。

所有参数为仿真设定值，无企业实测数据。当前风险优先策略在三组初始工况下停工时间较长，完整保留结果，后续需要研究等待公平性与运力约束。不宣称全局最优或现场应用。

缺料停工指标为四工位累计的工位·分钟；初始时四工位已各投入1件在制品，因此初始显示库存相应减少1件。

## 文件

- `index.html`：网页界面
- `engine.js`：独立仿真计算
- `app.js`：交互、图表及CSV导出
- `test.cjs`：计算规则检查，可在Node.js环境运行
- `verification.json`：现有参数下的检查与对比结果
